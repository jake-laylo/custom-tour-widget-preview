# custom-tour-widget-preview

Live preview pages for custom-styled Laylo tour widgets. Each page runs the real Laylo embed, so what you see here is what the artist's site will show.

## How it's laid out

- `previews/` is the only folder Cloudflare Pages publishes (set as the build output directory, no build command).
- Each preview lives in its own folder: `previews/<artist>-<first 8 characters of the drop ID>/index.html`, published at `https://<site>.pages.dev/<artist>-<id>/`.
- Re-running the skill for the same drop overwrites that drop's folder, so links already sent to a customer stay current.
- Every page is hidden from search engines (`robots.txt`, `_headers`, and a `noindex` meta tag). There's deliberately no index of previews, so customers can't browse other artists' pages.

Pages are generated by the Laylo tour widget skill in Claude. Don't put anything outside `previews/` that shouldn't be public.
